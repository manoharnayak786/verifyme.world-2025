🎯 Suggested Stack (Lean / Bootstrapped, 0-₹ initial cost)
If I were you and starting today with no funding, here’s the lean stack I'd pick:
Frontend + basic UI → Vercel (React / Next.js)
Backend APIs + business logic + certificate generation + QR + hash logic → Node.js backend on Render / Railway
Database + user management → Supabase (hosted) or Postgres on Railway / Render
Auth + user identity → Supabase (built-in) or ZITADEL for more advanced needs
Admin dashboard / Issuer dashboard (issue certs, manage users) → Build minimal in backend + React; or use ToolJet / Budibase for faster admin UI
Certificate generation (PDF + QR) + hash generation → Use open-source libraries (e.g. PDFKit / jsPDF / qr-code-generator) inside backend — no cost
Optional: Blockchain layer for tamperproof records → Integrate a lightweight blockchain or permissioned ledger; maybe later when you have some adoption. Research shows blockchain-based certificate verification using QR codes + decentralized apps is cost-effective vs traditional systems. (ResearchGate)
⚠️ What to Watch Out For / When You May Need to Pay
Free-tier hosting often comes with usage limits (requests, bandwidth, storage) — good for MVP and small user base, but if VerifyMe.world grows, you’ll need to move to paid plan.
Auth and user-management tools have free-tier limits. For massive scale or high security requirements you may need dedicated infra.
Blockchain integration — though technically possible with open-source frameworks — might have gas / transaction costs (if using a public chain), or infrastructure maintenance if you host a private chain. So start with centralized + hash-storage; add blockchain later only if needed.
You must write (or re-use) the logic for certificate issuance, PDF + QR generation, verification API — some dev effort needed even if the hosting is free.
